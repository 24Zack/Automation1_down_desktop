
# Sorting your desktop and download files for MacOS

This small project was made so that I could sort out automatically the mess in my download folder and desktop folder into specific folders (pdf,HEIC,other)




## Prerequisites

You need to install python3 (macOS)

```bash
    brew install python
```
    

## How to run the code
For sorting the desktop directory
```bash
  python3 destkop.py
```

For sorting the downloads directory
```bash
  python3 down.py
```
